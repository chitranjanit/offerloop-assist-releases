# OfferLoop Assist for Windows

OfferLoop Assist is a focused desktop companion for developer interview practice. It can transcribe short audio segments, help structure technical answers, explain screenshots, and keep the current question and response in one compact workspace.

## Download

Download the current Windows installer from the repository's **Releases** page:

- `OfferLoop-Assist-Setup-1.0.0-x64.exe` — recommended installer
- `OfferLoop-Assist-Portable-1.0.0-x64.exe` — portable version

Do not download installers from unofficial mirrors. Compare the downloaded file against `SHA256SUMS.txt` in the release assets when verification is required.

## Start using Assist

1. Create or sign in to your account at [OfferLoop Assist](https://www.offerloop.in/assist).
2. Choose a prepaid minute pack and complete secure payment.
3. Download and install the Windows application.
4. Open OfferLoop Assist and select **Continue with OfferLoop**.
5. Approve the displayed device in your browser.
6. Return to the desktop application and run the audio check before starting a practice session.

The desktop app never asks customers to enter an OpenAI or other AI-provider API key.

## Requirements

- Windows 10 or Windows 11, 64-bit
- Working microphone or Windows meeting-audio output
- Internet connection
- An active OfferLoop account with available Assist minutes

Read [INSTALL.md](INSTALL.md) for the complete setup walkthrough and [SUPPORT.md](SUPPORT.md) for troubleshooting.

## Responsible use

Use Assist for interview preparation, mock interviews, learning, and situations where AI assistance is permitted. Respect an interviewer’s rules, confidentiality obligations, employer policies, and applicable law. Do not submit confidential source code, credentials, personal data, or proprietary interview material.
