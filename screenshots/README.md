# Screenshot checklist

Capture screenshots from the packaged customer build using demonstration data only:

1. `workspace-answer.png` — question, structured answer, and code block.
2. `secure-sign-in.png` — signed-out account connection screen.
3. `audio-check.png` — audio source and level check without personal device names.
4. `account-recharge.png` — ₹3.50/min pricing and example balance.

Use a clean Windows profile. Remove emails, real names, hostnames, payment references, interview content, notifications, other applications, and browser tabs before capture. Prefer 16:9 PNG at 1600×900 or larger, then export an optimized WebP for the website.
