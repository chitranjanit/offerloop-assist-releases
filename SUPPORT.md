# OfferLoop Assist support

## Payment completed but balance did not update

1. Wait two minutes and refresh https://www.offerloop.in/account/assist.
2. Confirm that the payment shows as captured in your payment method.
3. Do not pay again with a new order immediately.
4. Contact support with your registered email, approximate payment time, amount, and Razorpay payment reference. Never send card, bank, UPI PIN, password, or OTP details.

## Desktop will not connect

- Start a new connection from the desktop; approval links expire after five minutes.
- Approve only the device name displayed by your own application.
- Ensure the browser and desktop use the same OfferLoop account.
- Revoke unused devices from the account page if the device limit is reached.

## No meeting audio

- Select **Meeting audio** or **Meeting + Microphone**.
- Set the meeting application's speaker to the same device as Windows output.
- Play test audio and check the level meter.
- Reconnect Bluetooth headphones if Windows changed the active output device.

## Microphone is not detected

- Confirm Windows microphone access is enabled for desktop applications.
- Select the intended microphone in Windows before restarting Assist.
- Close applications that exclusively control the microphone.

## Screenshot does not work

- Confirm the Assist account has an active balance.
- Keep the target content visible before using `Ctrl+Alt+S`.
- Do not capture passwords, private messages, customer data, or confidential source code.

## Contact

Use the official contact form: https://www.offerloop.in/contact

Include the application version, Windows version, the visible error message, and steps to reproduce. Do not include passwords, API keys, payment credentials, private interview recordings, or confidential screenshots.
