# Install and connect OfferLoop Assist

## 1. Create your account and add minutes

1. Visit https://www.offerloop.in/assist.
2. Select a 30, 60, or 120-minute pack.
3. Create an account or sign in.
4. Review the selected time and amount.
5. Select **Pay** and complete Razorpay checkout.
6. Wait until the page confirms that payment was verified and the balance was updated.

Closing checkout or seeing a payment-success screen does not by itself add credits. OfferLoop adds minutes only after secure server verification.

## 2. Download

Open the latest GitHub Release and download one of these files:

- **Setup**: `OfferLoop-Assist-Setup-1.0.0-x64.exe` — recommended for most users.
- **Portable**: `OfferLoop-Assist-Portable-1.0.0-x64.exe` — runs without installation.

Keep the installer only if it came from the official OfferLoop Assist Releases repository.

## 3. Install

1. Close older OfferLoop Assist versions.
2. Open the downloaded Setup file.
3. Choose an installation folder if prompted.
4. Finish installation and open OfferLoop Assist.

The current beta build may show a Windows publisher warning until code signing is enabled. Do not bypass a warning if the filename, source, or checksum differs from the official release.

## 4. Connect your account

1. In the desktop app, choose **Continue with OfferLoop**.
2. Your browser opens a short-lived device approval page.
3. Check that the device name matches your computer.
4. Choose **Approve desktop**.
5. Return to OfferLoop Assist. Your current balance should appear automatically.

Never approve a device connection you did not start yourself.

## 5. Configure audio

Open the workspace menu and select an audio source:

- **Meeting audio** — hears computer/meeting playback.
- **Microphone** — hears only your microphone.
- **Meeting + Microphone** — combines both sources.

Use **Test audio** and confirm that the level moves when speech is playing. For meeting audio, set both Windows output and the meeting application's speaker to the same headphones.

## 6. Use the workspace

- Select **Listen** to begin capturing short speech segments.
- Review and edit the transcribed question before sending it.
- Choose Theory, Coding, Design, or Auto mode.
- Press Send or `Ctrl+Alt+Enter` to request guidance.
- Use `Ctrl+Alt+S` for screenshot assistance.
- Use `Ctrl+Alt+B` to show or hide the window.

Assist charges active listening from the server balance in 15-second intervals. Stop listening when it is not needed.

## 7. Manage the account

Visit https://www.offerloop.in/account/assist to:

- View the current minute balance
- Recharge minutes
- Review minute activity
- See connected devices
- Revoke a device

If a payment was deducted but minutes do not appear after several minutes, do not create repeated payments. Save the Razorpay reference and contact support.
