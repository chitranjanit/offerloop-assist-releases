Production dependencies
-----------------------

OfferLoop Assist also bundles npm packages and their transitive dependencies.
Each dependency remains subject to its own licence and copyright notices. The
package lockfile records the exact resolved dependency versions used by a
release.

Before every public release, the release owner must generate and review a
production dependency licence inventory and append any attribution or notice
text required by the exact bundled versions. This file is not a substitute for
licence texts that a dependency requires to be reproduced in full.

Removed dependency record: Sharp and libvips
--------------------------------------------

An earlier development revision used Sharp/libvips for legacy screenshot
conversion. These packages were removed before the current release candidate
and are not intended to be distributed. The final artifact inspection must
confirm that no Sharp/libvips package or binary remains.
